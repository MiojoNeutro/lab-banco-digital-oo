# Banco Digital com Java e POO

Este repositório faz parte de um **lab da DIO** com foco em reforçar os conceitos de **Programação Orientada a Objetos (POO)** utilizando Java.  

O projeto simula um **banco digital**, explorando os pilares da POO em um contexto prático e intuitivo.

---

## 📌 Objetivo
O objetivo principal é aplicar e consolidar conhecimentos de **abstração, encapsulamento, herança e polimorfismo** em Java, desenvolvendo uma solução prática de um sistema bancário.

---

## 🛠️ Descrição do Projeto
- Implementação de contas bancárias (corrente e poupança).  
- Operações básicas como saque, depósito e transferência.  
- Estrutura de classes organizada para evidenciar os conceitos de POO.  

O projeto inicial foi disponibilizado como referência pela DIO. A partir dele, é possível **reproduzir a solução** e também propor **melhorias e evoluções**.

---

## 🚀 Próximos Passos
- Criar relatórios de clientes e transações.  
- Implementar persistência de dados (salvar histórico de operações).  
- Adicionar interface gráfica ou API para interação.  

---

## 📚 Tecnologias Utilizadas
- **Java**  
- **Programação Orientada a Objetos (POO)**
